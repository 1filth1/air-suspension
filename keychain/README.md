# Keychain remote — TTGO T-Display

Брелок-пульт для системы управления пневмоподвеской. Плата — TTGO T-Display
(ESP32, IPS ST7789V 135×240, 1.14″), связь с контроллером — зашифрованный
ESP-NOW на канале 1, как у остальных пультов проекта.

Экран вертикальный: давление в ресивере, давления всех четырёх колёс и четыре
кнопки. Управление простое — две кнопки поднимают перед и зад, две опускают.

## Плата и распиновка

| Назначение | GPIO | Примечание |
| --- | --- | --- |
| Дисплей SCLK | 18 | 4-проводной SPI, 40 МГц |
| Дисплей MOSI | 19 | |
| Дисплей CS | 5 | |
| Дисплей DC | 16 | |
| Дисплей RST | 23 | |
| Подсветка | 4 | `analogWrite`, ШИМ |
| Кнопка «перед вверх» | 32 | на GND, внутренняя подтяжка |
| Кнопка «перед вниз» | 33 | на GND, внутренняя подтяжка |
| Кнопка «зад вверх» | 25 | на GND, внутренняя подтяжка |
| Кнопка «зад вниз» | 26 | на GND, внутренняя подтяжка |
| Батарея | 34 | делитель 1:2, включается пином 14 |

Кнопки подключены между GPIO и GND, `INPUT_PULLUP`, активный уровень — низкий.
Все четыре пина в RTC-домене, так что позже их можно использовать для
пробуждения из глубокого сна.

## Поведение

- Экран обновляется по телеметрии контроллера (250 мс): ресивер, четыре колеса,
  тонкие полоски-индикаторы, значок состояния линка и заряд батареи.
- Удержание кнопки открывает клапаны соответствующей оси: перед — колёса FL/FR,
  зад — RL/RR. Команда повторяется каждые 180 мс.
- Отпускание отправляет отмену по обоим колёсам оси.
- Если нажать обе кнопки одной оси, побеждает нажатая последней.
- Подъём блокируется, пока контроллер не присылает валидное давление ресивера:
  без показаний ресивера качать вслепую нельзя.
- После потери и восстановления связи кнопку нужно отпустить и нажать заново —
  пульт не возобновляет качание сам.
- Контроллер закрывает клапаны через `manualTimeoutMs` (2 с по умолчанию) без
  свежих команд, поэтому потеря связи не оставляет клапан открытым.

## Протокол

Используется только та часть протокола, которая одинакова в конфигурациях
контроллера v2 (`main`) и v3 (release candidate), поэтому пульт работает с
обеими прошивками:

| Пакет | Направление | Назначение |
| --- | --- | --- |
| `E1 01` | пульт → broadcast | поиск контроллера |
| `E1 81` | контроллер → пульт | ответ в открытом виде |
| `E1 02` | пульт → контроллер | подтверждение и heartbeat раз в 500 мс |
| `A1` + `float[5]` + `flags` | контроллер → пульт | телеметрия: FL, FR, RL, RR, ресивер |
| `B1 20..27` | пульт → контроллер | импульс на одно колесо: чётный — накачать, нечётный — стравить |
| `B1 30..33` | пульт → контроллер | отмена импульса на колесе |
| `B1 2F` | пульт → контроллер | закрыть всё и выключить компрессор |

Кадры настроек (`0xA2`, `0xA3`, `0x43`, `0x44`, `0x45`) пульт не использует: они
различаются между v2 и v3, а брелку они не нужны.

Флаги телеметрии: бит 0 — все датчики в норме, бит 1 — работает компрессор,
бит 2 — компрессор заблокирован контроллером. На экране это `SENS`, `PUMP` и
`LOCK` соответственно.

## Сборка и прошивка

```bash
cd keychain
pio run -e keychain
pio run -e keychain -t upload
```

Скетч несёт собственный драйвер ST7789, поэтому TFT-библиотека не нужна и
`User_Setup.h` править не требуется. Из внешнего — только Adafruit GFX ради
примитивов рисования и встроенного шрифта.

Скетч собирается и на Arduino-ESP32 2.0.x (PlatformIO, как остальные пульты
проекта), и на 3.x (свежая Arduino IDE): сигнатуры колбэков ESP-NOW в этих
версиях различаются, и обе ветки закрыты через `ESP_ARDUINO_VERSION_MAJOR`.

## Что проверить при первом включении

1. **Направление и смещение окна.** Панель 135×240 занимает часть памяти
   240×320, поэтому в драйвере заданы `COL_OFFSET = 52` и `ROW_OFFSET = 40`.
   Если картинка съехала на несколько пикселей — правьте эти две константы.
2. **Цвета.** Если красный и синий поменялись местами, замените `0x00` в
   `MADCTL` на `0x08` (BGR) в `ST7789Spi::begin()`.
3. **Порядок кнопок.** Проверьте, что «перед вверх» действительно поднимает
   переднюю ось, а не заднюю: сопоставление `BTN_FRONT_*` / `BTN_REAR_*` с
   колёсами 0–3 задано в `pumpAxis()`.
4. **Подсветка.** Если экран тёмный, но данные идут, проверьте `LCD_BL` (GPIO4)
   и полярность подсветки на вашей ревизии платы.
5. **Батарея.** Процент считается по делителю 1:2 на GPIO34 с питанием от
   GPIO14. Если на вашей ревизии делитель не такой, отключите индикатор
   (`-DKEYCHAIN_BATTERY=0`) — на управление это не влияет.

## Ограничения

- Ключ ESP-NOW зашит в исходник и совпадает с ключом контроллера — так же, как
  в остальных пультах проекта. Пока ключ лежит в публичном репозитории, любой
  ESP32 в радиусе может привязаться к контроллеру. Это надо выносить в NVS и
  делать сопряжение по кнопке на контроллере.
- Пресетов и настроек нет: брелок только показывает давление и двигает оси.
- Глубокого сна нет — плата всё время питается от аккумулятора. Кнопки уже на
  RTC-пинах, так что сон по `EXT1` добавляется без переделки схемы.
- Стравливание не ограничено снизу ни здесь, ни в контроллере: колесо можно
  спустить до нуля, если держать кнопку.
- Прошивка пока не включена в release-workflow и веб-флешер — только сборка из
  исходников.
