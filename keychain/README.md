# Брелок-пульт TTGO T-Display

Брелок для контроллера пневмоподвески на ESP32 с экраном ST7789V 135×240. Он показывает давление ресивера и четырёх колёс, статус связи и батарею. Связь с контроллером — ESP-NOW на канале 1.

## Управление

У брелока две кнопки: SELECT (GPIO0) и CONFIRM (GPIO35).

- В обычном режиме короткое нажатие SELECT переключает выбранный пресет. На экране показываются имя и четыре целевых давления, полученные от контроллера.
- Короткое нажатие CONFIRM отправляет выбранный пресет контроллеру. Для этого нужны связь и полученные настройки.
- Удержание SELECT около двух секунд включает ручной режим.
- В ручном режиме SELECT перебирает восемь действий: заполнение и стравливание каждого из колёс FL, FR, RL и RR. Удерживайте CONFIRM для выбранного действия; отпустите её, чтобы прекратить команду. Если связь или свежая телеметрия пропали, пульт отменяет активную команду и требует отпустить CONFIRM перед продолжением.
- Ручной режим завершается после двух секунд без нажатий.

Контроллер остаётся источником целевых давлений и ограничений. Пульт не редактирует пресеты. Контроллер должен оставаться авторитетным и самостоятельно ограничивает давление и длительность ручного управления.

## Плата и распиновка

| Назначение | GPIO | Примечание |
| --- | ---: | --- |
| Дисплей SCLK | 18 | 4-проводной SPI, 40 МГц |
| Дисплей MOSI | 19 | |
| Дисплей CS | 5 | |
| Дисплей DC | 16 | |
| Дисплей RST | 23 | |
| Подсветка | 4 | ШИМ через `analogWrite` |
| SELECT | 0 | Активный низкий уровень, `INPUT_PULLUP` |
| CONFIRM | 35 | Активный низкий уровень; используется штатная подтяжка платы |
| Батарея | 34 | Делитель 1:2, включается GPIO14 |

## Протокол и безопасность связи

Пульт использует обнаружение ESP-NOW (`E1 01` / `E1 81`), зашифрованное подтверждение и heartbeat (`E1 02`), телеметрию (`A1`), запрос настроек (`B1 42`), запуск пресета (`B1 44`) и ручные команды (`B1 20..27`, `B1 30..33`, `B1 2F`). Контроллер должен быть обновлён совместимой прошивкой из того же релиза.

**Критически важно:** текущая прошивка содержит общий ключ ESP-NOW в исходном коде; этот ключ не уникален для установки и публичен вместе с репозиторием. Шифрование с таким ключом не является безопасным сопряжением устройств. Не используйте эту систему на дороге и не подключайте к ней автомобильные исполнительные механизмы до реализации уникальных ключей и надёжного сопряжения.

## Сборка и прошивка

```bash
cd keychain
pio run -e keychain
pio run -e keychain -t upload
```

Сборка использует PlatformIO, Arduino-ESP32 и Adafruit GFX. Драйвер ST7789 включён в `main.cpp`.

## Проверки при первом включении

1. Проверьте ориентацию и положение изображения; драйвер использует `COL_OFFSET = 52` и `ROW_OFFSET = 40`.
2. Проверьте цвета. При перестановке красного и синего измените BGR-бит `MADCTL` в `ST7789Spi::begin()`.
3. Убедитесь, что SELECT и CONFIRM работают согласно таблице распиновки.
4. Если экран тёмный, проверьте GPIO4 и полярность подсветки конкретной ревизии платы.
5. Индикатор батареи предполагает делитель 1:2 на GPIO34 с питанием от GPIO14. Если на вашей ревизии его нет, соберите с `-DKEYCHAIN_BATTERY=0`.

## Ограничения

- Это кандидат для стендовой проверки, не дорожная система безопасности. Прежде чем подключать пневматические исполнительные механизмы, испытайте всю систему с безопасным источником давления и независимой защитой.
- Потеря связи не заменяет аппаратную защиту: должны быть проверены fail-closed состояние клапанов, пределы давления, watchdog/timeout и отдельное аварийное отключение.
- Глубокий сон в текущей прошивке брелока не реализован.
