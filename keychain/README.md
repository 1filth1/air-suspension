# Keychain remote — TTGO T-Display

Компактный пульт для системы управления пневмоподвеской. Плата — TTGO
T-Display (ESP32, IPS ST7789V 135×240, 1.14″). Связь с контроллером —
зашифрованный ESP-NOW на канале 1.

Экран показывает давление в ресивере и четырёх колёсах. В нижней строке
отображаются выбранный пресет, его имя из контроллера и целевые давления
FL/FR/RL/RR в dbar.

## Управление

На компактной плате используются две встроенные кнопки:

| Кнопка | Короткое нажатие | Действие |
| --- | --- | --- |
| SELECT (GPIO0) | Переключить PARK → DRIVE → LIFT | Выбор пресета контроллера |
| CONFIRM (GPIO35) | Активировать выбранный пресет | Отправляет контроллеру команду B1 44 |
| SELECT (удержание 2 с) | Войти в ручной режим | Начать с FL вверх |
| SELECT в ручном режиме | Следующее колесо/направление | Перебор FL/FR/RL/RR вверх/вниз |
| CONFIRM в ручном режиме | Удерживать клапан открытым | Отпускание закрывает клапан |

После потери связи ручное управление блокируется до отпускания кнопок.
Автоматическое выполнение пресета запускается только коротким нажатием
CONFIRM при выбранном пресете и установленной связи.

## Синхронизация настроек

Контроллер — единственный источник имён и целевых давлений пресетов. Брелок
не хранит отдельную редактируемую копию и не изменяет настройки.

- После соединения брелок запрашивает настройки командой B1 42.
- Контроллер отвечает кадром SettingsFrame версии 2 (114 байт).
- Брелок проверяет маркер, версию и контрольную сумму перед применением.
- При потере связи настройки запрашиваются заново после переподключения.
- Короткий SELECT выбирает один из трёх пресетов; CONFIRM запускает выбранный.

Основной пульт T-Display остаётся местом редактирования имён и целевых
давлений. Сохранённые значения и имена отправляются контроллером обоим
пультам.

## Протокол

| Пакет | Направление | Назначение |
| --- | --- | --- |
| E1 01 | пульт → broadcast | поиск контроллера |
| E1 81 | контроллер → пульт | ответ на поиск |
| E1 02 | пульт → контроллер | подтверждение и heartbeat |
| A1 + float[5] + flags | контроллер → пульт | телеметрия |
| A2 + SettingsFrame v2 | контроллер → пульт | имена и целевые давления пресетов |
| B1 42 | пульт → контроллер | запрос настроек |
| B1 44 + индекс | пульт → контроллер | запуск PARK/DRIVE/LIFT |
| B1 20..27 | пульт → контроллер | ручное управление отдельным колесом |
| B1 30..33 | пульт → контроллер | отмена ручного импульса |

Кадр настроек содержит контрольную сумму; несовпадающий кадр не применяется.
Контроллер продолжает самостоятельно проверять пределы давления и управлять
клапанами. Эта прошивка предназначена для стендовой проверки и не является
подтверждением безопасности системы на дороге.

## Сборка и прошивка

```bash
cd keychain
pio run -e keychain
pio run -e keychain -t upload
```

Скетч использует собственный драйвер ST7789 и библиотеку Adafruit GFX.
